Siri

Talk to TidyNest through Siri, using a Shortcut on this phone. Your Siri link is private: it lets the Shortcut add things as you, so don't share it.

Make the Shortcut (once)

  1. Tap Copy link above, then open the Shortcuts app and tap +. Name the shortcut TidyNest (it's what you'll say to Siri).
  2. Add the action Dictate Text.
  3. Add Get Contents of URL. Tap URL and paste your link. Tap the arrow to show more, set Method to POST and Request Body to JSON, then Add new field → Text: key text, and for the value pick Dictated Text.
  4. Add Speak Text (it fills in Contents of URL by itself). Tap Done.

Then say "Hey Siri, TidyNest", and…

  • "Add milk and bread to the shopping list"
  • "Remind me to put the bins out tonight at 6"
  • "Remind us to pay the rates on the 15th"
  • "Add event dentist on Friday at 3"
  • "Countdown to Christmas on the 25th of December"
  • "What's on today?" or "What's on tomorrow?"

Quicker ones: duplicate the Shortcut and rename it. For What's on today, swap Dictate Text for a Text action saying "what's on today". For Add to shopping list, keep Dictate Text and add a second JSON field: key list, value Shopping.
